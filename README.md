# POP! Craft Soda Co. — Brand Identity Kit

A fictional craft soda brand, designed **bold & playful**: geometric bubble
letterforms, a hot-pink/tangerine palette, chunky borders and hard offset
shadows. Everything is code (SVG + CSS), so it's infinitely scalable and
easy to recolor or animate.

## Files

| File | What it is |
|---|---|
| `guidelines.html` | **Start here.** Full brand guidelines page — open in a browser |
| `logo-pop-primary.svg` | Primary wordmark, one-color ink |
| `logo-pop-deluxe.svg` | Two-tone wordmark (pink O, yellow !) for light backgrounds |
| `logo-pop-stacked.svg` | Vertical lockup: bubble mark + wordmark + tagline |
| `logo-pop-reversed.svg` | White wordmark for dark/photo backgrounds |
| `logo-pop-icon.svg` | App icon / avatar (512px, works down to 40px) |
| `favicon.svg` | Browser favicon |
| `brand-tokens.css` | Color, type, radius, border & shadow variables |

## Quick use

- **Web:** link `brand-tokens.css`, use `var(--pop-bubblegum)` etc.
- **Print/Figma:** import any SVG — they're plain vectors, no fonts needed
  for the wordmark (drawn as paths).
- **Recoloring:** every logo is stroke-based; change the `stroke` color
  and stroke-width stays proportional.

## The palette

- Cream `#FFF4E4` (60%) · Ink `#191022` (25%)
- Bubblegum `#FF3F8E` (8%) · Tangerine `#FF6B2C` (4%)
- Fizzy Yellow `#FFC93C` (2%) · Grape Fizz `#6C2BD9` (1%)

## Type

- Body: **DM Sans** (400/500/700)
